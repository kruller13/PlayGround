## Evolution Gate Shooter

A portrait-first 3D action gate-runner for Android browsers. Auto-fire is always on; drag (or use the lane buttons / arrow keys) to dodge, choose a gate, and evolve through six eras in one continuous run.

- **Run locally:** `npm install` then `npm run dev`
- **Production build:** `npm run build` (served from `dist/`)
- **Controls:** drag anywhere on the field, tap the side arrows, or use ←/→ and A/D. `Esc` pauses.
- **Persistence:** best score, cores, runs, wins, seen eras, and Evolution Lab upgrades are stored in `localStorage` under `evo-gate-shooter-v1`.
- **Content:** six procedural eras, gate builds, enemy archetypes, drones, boss encounters, victory rewards, meta upgrades, and an era codex. All geometry, textures, and audio are generated at runtime; no external game assets are required.
